# Solution Vision: agente-black-seller

> Agent Plugin conforme a Agent Plugins v1.0.0 que encapsula el metodo de venta de Alex Bobadilla.

## Identity

### Description

agente-black-seller es un plugin de agente portable que destila el conocimiento de venta de Alex Bobadilla — capturado en un curso de tres horas impartido a Eduardo Munoz Luna — en un conjunto de skills invocables desde Claude Code y Codex. El curso vive hoy en la memoria de quien lo tomo y en una grabacion; ahi no es operable. El plugin lo convierte en metodo aplicable en el momento de la venta real: diagnostico de prospecto, construccion de guion, manejo de objeciones, cierre y seguimiento. Alex Bobadilla es el creador del metodo y la fuente de autoridad; el plugin es su vehiculo, no su reemplazo.

El proyecto no inventa metodologia de venta. Su unica fuente de verdad es el material del curso. Todo lo que el agente afirma debe poder rastrearse a esa fuente.

## Outcomes

| **Outcome** | **Description** |
|-------------|-----------------|
| **Metodo Operable** | El metodo de venta de Alex Bobadilla queda disponible bajo demanda dentro del flujo de trabajo real, sin depender de recordar el curso ni de volver a verlo. |
| **Fidelidad a la Fuente** | El agente responde segun el metodo de Alex Bobadilla, no segun conocimiento generico de ventas de un modelo de lenguaje. La voz y los criterios son los suyos. |
| **Trazabilidad** | Cada afirmacion, guion y criterio del agente cita el punto del curso del que proviene. Lo que no tiene fuente, no se afirma. |
| **Portabilidad** | El mismo paquete funciona en Claude Code y en Codex sin bifurcar el contenido, gracias a la conformidad con Agent Plugins v1.0.0. |
| **Conformidad Verificable** | La conformidad con el estandar no es una declaracion sino una prueba automatizada que corre en cada cambio. |
| **Aplicabilidad** | Cada skill produce un artefacto usable — un guion, un diagnostico, una secuencia de seguimiento — no un resumen teorico. |
| **Evolucion Trazable** | El conocimiento crece cuando llegan fuentes nuevas de Alex Bobadilla, sin romper la trazabilidad de lo ya destilado. |

## Non-Goals

- No es un agente que vende de forma autonoma a clientes finales por WhatsApp u otro canal.
- No es un producto SaaS para terceros ni una plataforma para alumnos de Alex Bobadilla.
- No sustituye la formacion directa con Alex Bobadilla.
- No genera metodologia de venta propia ni mezcla escuelas ajenas al material fuente.
